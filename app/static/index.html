登阶

让长期目标,
真正走进你的每一周。

刷完一门公开课、期中前读完一本书、把绩点稳住——这些目标之所以停在开学那天,不是因为你不努力,而是它们从没和你的课表、作业、通知放在同一本账上。

  • 懂你的课业课表、Canvas 作业、学校邮件和长期目标进同一本账,一眼看清这周排不排得下。
  • 把愿望变成任务说一句目标,AI 拆成带时长和截止日的具体任务,你改过、确认了才算数。
  • 每天一次回声打开就知道今天做什么;做不完也没关系,登阶帮你把明天排轻一点。
  • 和同伴一起登阶邀请码建组,共同目标各自认领,看得见彼此的进度。

            演示脚本

            按 PRD 的顺序拍。「灌入演示数据」会写入一份示例课表、一个已拆解的目标、两条 Canvas 作业和两条邮件事项(待确认),你可以从任一步开始;真实课表用「接入」页上传 PDF 覆盖即可。

            1. 立目标,AI 拆解,和 AI 讨论一轮目标页输入「期中前刷完 MIT 18.01 前四单元」→ AI 拆解 → 在讨论栏写「合并成 5 个,每周留一次复习」→ 确认入池。
            2. 导入课表接入页上传教学信息网导出的 PDF(或粘贴文字)→ 解析 → 保存。保存后本周可投入自动变成 42 − 课时。
            3. 拉作业、读邮件,确认入账接入页点「拉取作业」「读取邮件」(或一键导入粘 JSON)→ 待确认面板里逐条「计入」,看时间账的数字变化。
            4. 看这周的账今日页顶部:「这周还有 N 小时空余 / 排多了 N 小时」。日历页看整月的课与任务。
            5. 每日复盘今日页对任务点「完成」「推迟」;然后点「让登阶把明天排轻一点」,看预览,点「就这么办」。
            6. DDL 与结算DDL 页看倒计时;到期目标点「达成了 / 延期到 / 放弃」。
            7. 小组共进建组拿邀请码,另一个账号加入;立共同目标「共读《线性代数应该这样学》前四章」,各自认领任务,看完成率。
